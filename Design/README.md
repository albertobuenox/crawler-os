# Design System — Crawler OS

Sistema visual de **The System HUD**: interfaz holográfica de dungeon crawler, inspirada en Sword Art Online, HUDs de isekai y las referencias de `References/`.

Este folder es la fuente de verdad de diseño. Las reglas operativas para agentes están en `Rules/` y en `.cursor/rules/`.

## Referencias de origen

1. `References/futuristic components aesthetic.jpg`  
   Dashboard glass modular: cards translúcidas, stats cian, gráficos neón, mapa de puntos, CTA pill púrpura-azul.

2. `References/Futuristic Glass UI – Neon Dashboard Aesthetic.jpg`  
   HUD cósmico: bokeh, nested cards, botón gradiente naranja-rosa, botón outline neón, nav con glow por icono, gráfica dual magenta/azul.

## Principio único

La UI no es una web. Es un **sistema operativo de mazmorra proyectado en el aire**: paneles de cristal flotantes, luz neón en los cantos, datos vivos, mensajes del Sistema con personalidad.
