# Iconos de attack skills

Un archivo `.webp` por skill. El nombre es el **slug** del catálogo:

```
public/skills/attack/<slug>.webp
```

Ejemplos:

- `bow.webp`
- `back-claw.webp`
- `wrasslin.webp`
- `choke-out.webp`

Tamaño recomendado: cuadrado (256×256 o 512×512). Hasta que el archivo exista, la UI muestra el icono por defecto.
